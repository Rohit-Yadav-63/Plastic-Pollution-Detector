# Dataset

- Name: Plastic Waste Computer Vision Dataset
- Author: Edwin Daza Saavedra (Roboflow Universe)
- Source link: https://universe.roboflow.com/edwin-daza-saavedra-s-workspace/plastic-waste-ag4eg
- Images: 12,484 (version 1.1, 512x512)
- Classes (3): plastic bag, plastic bottle, plastic cup
